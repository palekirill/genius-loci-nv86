# genius_loci_nv86

short interactive point-and-click experience built with html5 canvas and javascript, created with love and entirely with the help of ai.

## features

- desktop-only experience (not optimized for mobile)
- best viewed in google chrome
- first-person interactive point-and-click navigation
- branching paths with multiple loops back to the start

## instructions

- click on interactive parts
- explore branching paths
- repeat
